# TL Standard Plugin Manual  
  
## Quick Overview  
  
The Standard Translation plugin provides translation capabilities by wrapping the `translators` Python module.  
  
This module must be installed for the plugin to function.  
Only the `google` provider has been thoroughly tested.  
Not all languages are supported by all providers.  
  
Check the [Github](https://github.com/uliontse/translators) for a list of supported languages.
